> **This project is retired.**
>
> As of rubytest 0.10.0 (2026-11), the summary reporter is built into
> [rubytest](https://github.com/rubyworks/rubytest): select it with
> `rubytest -f summary`. This gem is no longer needed.
>
> This repository preserves rubytest-summary, last released as 0.1.0 in
> 2014. It is no longer maintained.
